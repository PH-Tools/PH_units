# ph_units/ — the package

Unit parsing + conversion for Passive House workflows. See `../context/ARCHITECTURE.md`.

## Modules

- `converter.py` — `convert(value, from_unit, to_unit)`.
- `parser.py` — `parse_input("{value} {unit}") -> (value, unit)`.
- `unit_type.py` — the `Unit` type (a `float` subclass carrying unit info; math, inversion, JSON/dataclass serialization).

## Subfolder

- `unit_types/` — the conversion registry, one module per dimension (area, density, energy, envelope, hvac, length, moisture_vapor_resistance, power, speed, temperature, volume, volume_flow). `_base.py` is the shared base. See `unit_types/.index.md`.

## Notes
- IPy2.7-safe, no runtime deps. Tests: `../tests/` (per-dimension).
