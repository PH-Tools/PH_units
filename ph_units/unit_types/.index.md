# unit_types/ — conversion registry

One module per physical dimension, each holding the conversion factors and the accepted unit aliases for that dimension. This is where all conversion knowledge lives; `../converter.py` reads from here and stays generic.

## Modules

`area`, `density`, `emissions_factors`, `energy`, `envelope` (U/R-value), `hvac`, `length`, `moisture_vapor_resistance`, `power`, `speed`, `temperature`, `volume`, `volume_flow`. `_base.py` is the shared base.

## Notes
- Add a unit by extending the right module (or adding a new one per `_base.py`) — register every alias spelling (e.g. `"FT"`, `"ft."`, `'`). See `../../context/CODING_STANDARDS.md`.
