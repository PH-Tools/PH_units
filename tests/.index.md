# tests/ — pytest suite

Per-dimension pytest suite. Run with `python -m pytest`.

## Contents

- One `test_<dimension>.py` per unit dimension (`test_areas.py`, `test_density.py`, `test_energy.py`, `test_envelope.py`, `test_hvac.py`, `test_lengths.py`, …).
- `test_converter.py` — the `convert()` path; `test_as_a.py` — the `Unit.as_a()` path.

## Notes
- A new dimension or alias needs a matching test case here — see `../context/CODING_STANDARDS.md`.
